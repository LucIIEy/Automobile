# 한템포 (OneTempo)

운전 중 급한 순간에 말 한마디만 하면, 상황에 맞는 우선순위로 지금 갈 곳 한 곳을 골라 내비게이션 경유지로 바로 안내하는 차량용 판단 도우미

## 주요 기능
- 음성 또는 화면의 '바로 선택' 카드로 상황 입력
- 상황별 의사결정 우선순위(해결 시간, 진입 가능성, 주차 여건, 정차 안전성, 안내 단순성)에 따라 한 곳만 제안
- "응" 한마디로 내비게이션 경유지 추가, "아니"라고 하면 다음 순위 제안

## 실행 방법
1. Pleos Connect 에뮬레이터를 실행합니다.
2. `apk/Individual_OneTempo_release.apk` 파일을 에뮬레이터 화면에 끌어다 놓아 설치합니다.
3. 앱을 실행하고 마이크와 위치 권한을 허용합니다.
4. 에뮬레이터 위치를 시연 지점으로 설정합니다. (아래 '필요한 설정' 참고)
5. 앱의 '시연용 목적지 설정'을 눌러 목적지를 먼저 설정합니다.
6. 마이크 버튼을 누르고 "화장실 급해"라고 말하거나, '바로 선택' 카드를 누릅니다.
7. 제안을 듣고 "응"이라고 답하면 내비게이션에 경유지가 추가됩니다.
    - 음성 인식이 어려운 환경에서는 화면의 '응, 가자 / 아니' 버튼을 사용할 수 있습니다.

## 테스트 환경 및 필요한 설정
- Android Studio, Kotlin
- minSdk 28, compileSdk 37
- 에뮬레이터 마이크 접근 허용 (음성 인식용)
- 에뮬레이터 위치를 경부고속도로 서울 방향 신갈 부근으로 설정
  ```bash
  adb emu geo fix 127.1050 37.2900
  ```
- 장소 정보와 장소별 점수는 시연 구간 주변의 샘플 데이터이며, 도착 시간은 직선거리 기반 추정값입니다.

## 개발에 사용한 Pleos Connect 에뮬레이터
- 시스템 이미지: Pleos Connect system image (API 34)
- 화면 규격: 2560 × 1440 px (160 dpi, 가로)
- ABI: arm64-v8a

## 사용한 Pleos Connect SDK
| SDK | 버전 | 활용 |
|---|---|---|
| SpeechToText | 3.3.1 | 요청과 "응/아니" 대답 인식 (ON_DEVICE) |
| TextToSpeech | 3.3.1 | 제안과 결과 음성 안내 (ON_DEVICE) |
| FusedLocation | 1.1.3 | 현재 위치 기반 거리·도착 시간 계산 |
| NaviHelper | 3.0.5 | 목적지 설정, 경유지 추가 |
| Vehicle | 2.3.2 | 피로 감지 기능에 활용 예정 (2차) |
